Privacy policy

Last updated: 17 October 2026 · Applies to MDV Plus 0.2.0 and this project website.

MDV Plus renders Markdown in your browser. The extension has no publisher-operated document upload service, advertising or analytics. Local processing still involves user data: clipboard text, document contents, settings, document URLs and scroll positions. Chrome synchronization and external resource requests are explained below.

1. Documents and clipboard

When you choose to open or paste clipboard text, open a file, or view a permitted Markdown page, MDV Plus processes its content to produce a formatted view. Editing and saving also use document text, the selected file name and, where supported, a browser-provided file handle and file metadata. The publisher does not receive these documents through the extension.

The extension reads the clipboard when you invoke a clipboard action; it does not continuously monitor it. Text read in the popup is temporarily placed in the extension’s local storage to hand it to the viewer. The viewer removes that transfer entry when it retrieves it. Entries older than one minute are not loaded as a new document, but this age check is not an automatic deletion timer. An unread entry can remain until it is retrieved, replaced or storage is cleared.

The open document is otherwise held in the viewer’s memory, not saved as an automatic document archive by MDV Plus. Changes are written to a chosen file or downloaded when you save. Your operating system, browser and any folder-sync service you use may separately retain files or restore browser sessions.

2. Settings and Chrome synchronization

MDV Plus uses chrome.storage.sync for preferences, including interface language, theme, parser settings, custom CSS and configured website origins and matching rules. Chrome may transmit and synchronize these settings through Google according to your browser/account settings. Markdown document bodies are not intentionally stored in synchronized settings. Do not put confidential information into custom CSS or website matching rules if you do not want it synchronized.

Chrome and Google process browser synchronization under their own terms and Google Privacy Policy. The publisher does not operate or control that service.

3. Website access and activity

To recognize Markdown, MDV Plus checks document URLs and content types where access is permitted. It injects its packaged viewer and supporting code into matching documents. Remote website access is optional and requires a browser permission grant; local-file access also depends on the browser’s file-access setting.

Reading positions may be stored locally using the document origin and path as a key, with a local extension-storage fallback if website local storage is unavailable. These entries reveal which documents have saved reading positions, but are not sent to the publisher. They are not a general browsing-history database.

The optional automatic-reload feature observes completed document requests and retrieves the open document again to update its view. This can generate additional requests to that document’s server. It is not used to build advertising or behavioral profiles.

4. External resources and recipients

“Rendered in your browser” does not mean that every document is network-free:

  • Document resources: external images, links you follow and resources referenced by custom CSS can contact their respective hosts. Those hosts receive the requested resource URL and normal network information, such as your IP address and browser request headers. Referrer information depends on the context and browser rules.
  • Emoji: if optional emoji rendering is enabled for Markdown pages, emoji images are loaded from cdn.jsdelivr.net/emojione/assets, operated through jsDelivr. The requested image identifies the emoji, and the CDN receives normal request metadata. See jsDelivr’s privacy policy.
  • Permitted document servers: viewing or automatically reloading remote Markdown contacts its hosting server. The server handles these requests under its own policies.
  • Google: browser synchronization can process the settings described above. Installation, updates and store interactions are also provided by Google, separately from document rendering.

These requests do not constitute a publisher-operated upload of the complete Markdown document. However, a document may itself contain resource URLs carrying sensitive information. Review untrusted content before displaying it, and disable optional features or use offline/network controls where appropriate. The extension’s executable rendering libraries are packaged with the extension rather than fetched from a remote script service.

5. Retention and your controls

  • Close the viewer to end that document’s active editing session. Closing it does not delete files you saved or guarantee deletion from browser session recovery.
  • Clipboard transfer storage is removed on retrieval as described above. Clear extension storage or uninstall to remove remaining extension-local entries.
  • Preferences and reading-position entries can remain until changed or cleared. Clear relevant website storage to remove reading positions stored there; uninstalling the extension alone does not necessarily clear website storage.
  • Manage synchronized data through Chrome’s synchronization and account controls. Uninstalling on one device does not guarantee immediate deletion of all synchronized copies.
  • Revoke optional website permissions, disable automatic reloading or emoji, and turn off file-URL access in the browser’s extension controls when not needed.
  • Files saved or downloaded remain under your control until you delete them. Their retention also depends on your backups and folder-sync services.

6. Limited use of data

User data is used only to provide the described Markdown viewing, editing, saving and related settings features. MDV Plus does not sell user data, use it for personalized advertising, or use or transfer it for creditworthiness or lending decisions. The publisher does not receive document content unless you voluntarily provide it, for example in a support email.

The use of data accessed through Chrome APIs complies with the Chrome Web Store User Data Policy and Limited Use requirements. Data is not used or transferred for unrelated purposes.

7. This website and support email

This static website includes no publisher-added analytics, advertising scripts, embedded third-party media, external fonts or tracking cookies. Its images and styles are served with the site. GitHub Pages hosts the site; GitHub processes technical request information, including IP addresses, under the GitHub Privacy Statement. Clicking external links opens the relevant third-party service.

If you email wegasolutions@googlemail.com, your address, message, attachments and normal email metadata are processed to answer the request. The mailbox is provided by Google/Gmail. Support correspondence is kept as needed to address the request and meet applicable obligations; you may request deletion where applicable. Do not send passwords or sensitive documents. Service providers may process data internationally according to their policies.

8. Contact and changes

For support, privacy questions or requests concerning data you have voluntarily sent to the publisher, contact wegasolutions@googlemail.com. Depending on applicable law, you may have rights to access, correction, deletion, restriction or objection, portability, and to complain to a supervisory authority. The publisher cannot retrieve documents stored only on your device; requests about Google or GitHub data may also need to be directed to those providers.

This policy will be updated when relevant behavior changes. The latest revision date appears at the top of this page.
